Graphit und Glas

Das Logo hat drei Materialien: einen matten Graphit-Balken, einen Tropfen aus Mint-Glas und eine kühle helle Platte. Die Oberfläche übernimmt sie als Rollen, nicht als Effekt: Graphit trägt, Glas hebt hervor, die Platte beruhigt. Für die Systemfenster gilt Findlings Disziplin.

1Vier Regeln

Mint heißt: läuft oder ist die Hauptaktion

Laufende Musik, laufender Timer, ein Termin, der jetzt stattfindet, Fortschritt im Timer-Ring und genau eine gefüllte Aktion je Ansicht. Information bleibt weiß, Nebensache grau. Höchstens zwei Mint-Stellen im Bild.

Die Insel bleibt schwarz

Sie verschmilzt mit der Notch, in hellem und dunklem Systemerscheinungsbild. Flächen darin sind Graphit aus dem Logo, nicht weißes Alpha. Hinter der Kamera liegt nichts.

Fenster sind Mac

Einstellungen, Aufgabenblatt und Zitatkarte folgen Hell/Dunkel. Gruppierte Form, Standardsteuerungen, Systemfarben für Text und Flächen; Brimlet bringt nur den Akzent mit.

11 pt ist die Untergrenze

Normaler Text 13 pt (Insel teils 12 pt), Hilfetext 11–12 pt, mindestens 4,5 : 1. Keine Versalien mit Sperrung, keine abgerundete Schrift: SF Pro, für Zitate New York.

2Farbe

Markenwerte stammen aus Resources/Icon/Brimlet.svg. Alle anderen Werte sind daraus in OKLCH abgeleitet (Farbton 165 für Mint, 255 für Graphit) und auf Kontrast geprüft. Kontraste stehen jeweils dabei.

5Kanten und Schatten

Insel

Kein Schatten. Eine innere Kante rgba(255,255,255,.09), 1 pt, an Seiten und Unterkante; die Oberkante bleibt offen, damit die Insel mit dem Bildschirmrand verschmilzt. Flächen darin mit 1-pt-Kante .08.

Glas

Die eine Lichtkante des Logos: gefüllte Mint-Flächen bekommen oben innen 1 pt Weiß mit 35–40 %. Sonst keine Verläufe, kein Leuchten, kein Weichzeichner in der Insel.

Zitatkarte und Fenster

Zitatkarte: 0 18 48 −12 Schatten 22 % (dunkel 55 %), dazu 0,5 pt Kante. Fenster und Blatt: Systemschatten von NSWindow, nichts Eigenes.

6Symbole

SF Symbols, Schnitt Medium in der Insel, Regular in Fenstern. Größen folgen dem Text daneben (Symbol 13 pt bei 12-pt-Tabs, 15 pt in Symboltasten, 18 pt Transport, 21 pt Toolbar). Jede Symboltaste hat .help() und .accessibilityLabel(). Kein Symbol als reine Dekoration neben Überschriften.

8Tastatur, VoiceOver, Fokus

Tastatur in der Insel

Reihenfolge: Kopf (auf-/zuklappen) → Tabs → cmux-Chip → Einstellungen → Inhalt von links oben nach rechts unten. ← → wechseln zwischen Tabs, Leertaste/↩ lösen aus, Esc schließt (wie heute, solange die Insel den Fokus hat). Im Aufgabenblatt: ↩ fügt hinzu, Esc bricht ab.

VoiceOver

Jede Symboltaste trägt ein Label und dieselbe Hilfe (.help): „Pause“, „Nächster Titel“, „Songtext zeigen“, „Im Kalender zeigen“, „Beitreten: Weekly team sync“. Die Zeitleiste bleibt ein einstellbares Element („Titelposition, 1:32 von 5:16“, ±5 s). Timer-Ziffern werden nicht jede Sekunde vorgelesen, nur Zustandswechsel. Gewählter Tab: .isSelected.

Fokus und Ziele

Fokusring 2 pt im Akzent mit 1–2 pt Abstand, auf Schwarz Mint, in Fenstern Jade, nie entfernt. Klickziele in der Insel mindestens 28 × 28 pt (Peek-Transport 28, Wiedergabe 30/40), Textaktionen 24 pt hoch über die volle Textbreite. Fenster nutzen die Standardgrößen von macOS.

Reduce Motion und Kontrast

Mit Reduce Motion springt die Insel auf ihre Größe, Inhalte blenden 150 ms über, der Equalizer steht. „Kontrast erhöhen“ hebt die Kanten von 8 auf 20 % Weiß und label3 auf label2 an.

9Komponenten und Zustände

Jede Steuerung in Ruhe, beim Zeigen, gedrückt, mit Tastaturfokus und gesperrt. Kontrast sinkt in keinem Zustand außer „gesperrt“. Fokus ist immer ein 2-pt-Ring im Akzent.

enum IslandColor {                       // immer dunkel, unabhängig vom System
    static let surface      = Color(hex: 0x111418)
    static let surfaceHover = Color(hex: 0x181C21)
    static let raised       = Color(hex: 0x23282F)   // Logo-Graphit
    static let label        = Color(hex: 0xF3F5F8)
    static let label2       = Color(hex: 0xACB2B9)
    static let label3       = Color(hex: 0x81878D)
    static let accent       = Color(hex: 0x60E7B4)   // Logo-Mint
    static let onAccent     = Color(hex: 0x04261B)
    static let hairline     = Color.white.opacity(0.08)
}
// Asset-Katalog: AccentColor  hell #227F5F · dunkel #1EA87B
//                OnAccent     hell #FFFFFF · dunkel #052A1E
//                QuoteSurface hell #F6F9FC → #EDF2F8 · dunkel #1A1E24

struct IslandButtonStyle: ButtonStyle {
    enum Kind { case primary, secondary }
    var kind: Kind = .primary
    @Environment(\.isEnabled) private var enabled
    func makeBody(configuration: Configuration) -> some View {
        configuration.label
            .font(.system(size: 12, weight: .semibold))
            .foregroundStyle(kind == .primary ? IslandColor.onAccent : IslandColor.label)
            .padding(.horizontal, 14).frame(height: 28)
            .background(RoundedRectangle(cornerRadius: 8, style: .continuous)
                .fill(kind == .primary ? IslandColor.accent : IslandColor.raised))
            .overlay(alignment: .top) {               // Glaskante
                RoundedRectangle(cornerRadius: 8, style: .continuous)
                    .strokeBorder(.white.opacity(kind == .primary ? 0.35 : 0.05), lineWidth: 1)
                    .mask(LinearGradient(colors: [.white, .clear], startPoint: .top, endPoint: .center))
            }
            .scaleEffect(configuration.isPressed ? 0.97 : 1)
            .opacity(enabled ? 1 : 0.4)
            .animation(.easeOut(duration: 0.12), value: configuration.isPressed)
    }
}

Kontraste nach WCAG 2.2 berechnet. Systemfarben in der Vorschau sind Annäherungen an macOS 14; in der App liefert macOS sie selbst. Symbole sind SVG-Nachbildungen der SF Symbols.
